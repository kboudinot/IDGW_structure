# Genetic population structure of gray wolves (_Canis lupus_) in Idaho using harvest data
Repository for code associated with analysis of population structure for gray wolves in Idaho using single nucleotide polymorphism (SNP) and microhaplotype data generated by Genotyping-in-Thousands by sequencing (GT-seq).

## Genotyping and bioinformatics
Delomas et al. 2023 pipeline: https://github.com/arianacerreta/IDGW-bioinformatics-pipeline


## R scripts
### filtering_microhaps.R

Data inputs: 
1. microhaplotype_genotypes_raw.csv
2. neutral_diagnostic_loci_new(in).csv
3. sample_metadata_regions.csv
4. relatedness_trioml.csv

Details: Script used for filtering data based on missingess per locus and genotype, diagnostic loci, replicates, and relatedness.

Output: structure_data.csv

## References 
Delomas, T. A., J. Struthers, T. Hebdon, and M. R. Campbell. 2023. Development of a microhaplotype panel to inform management of gray wolves. Conservation Genetics Resources 15:49–57.
