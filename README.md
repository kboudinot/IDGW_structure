# Genetic population structure of gray wolves (_Canis lupus_) in Idaho using harvest data

Repository for code associated with analysis of population structure for gray wolves in Idaho using single nucleotide polymorphism (SNP) and microhaplotype data generated by Genotyping-in-Thousands by sequencing (GT-seq).

# Genotyping and bioinformatics
Delomas et al. 2023 pipeline: https://github.com/arianacerreta/IDGW-bioinformatics-pipeline

# Description of CSVs
## GT-seq data processing
microhaplotype_genotypes_raw: Indiv, Locus, Allele1, Allele2, Allele1_count, Allele2_count, and p.\
neutral_diagnoslic_loci_new(in): Diagnostic, OG_locus_ID, Chr, BP, Locus, CanFam3.1_Chr, CanFam3.1_BP, and CanFam3.1_Locus.\
## Sample metadata
sample_metadata_regions: Sample, ID, MortYear,	GMU, and Region.
